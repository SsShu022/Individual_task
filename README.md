# Індивідуальне завдання: Створення та верифікація цифрового підпису на зображенні

## Вміст

Папка налічує в собі 5 файлів (окрім README):
* private_key.pem, public_key.pem - 4096-бітні приватний та публічний ключі RSA
* final_task.ipynb - Jupyter Notebook із повним кодом: генерація підпису, приховування, витяг та перевірка
* bird_original.png - оригінальне зображення
* signed.png - зображення з цифровим підписом

## Початок роботи та запуск коду
В коді використовується дві бібліотеки: **rsa** та **PIL**.

Файл 'final_task' містить розділ **Set up**, що надає код для інсталяції бібліотек через pip, а також ініціалізацію необхідних для коду імпортів.

Для того щоб інсталювати бібліотеки, ініціалізувати імпорти й основний код, необхідно послідовно запустити подані в розділах **Set up** і **Signature creation & verification** блоки коду

## Опис методу та використання

Для приховання цифрового підпису в зображенні було використано принципи LSB-стеганографії (LSB - Least Significant Bit)

Стеганографія - тайнопис, який кодує інформацію таким чином, що приховує сам факт її наявності. 

Least Significant Bit (LSB) - метод стеганографії, який дозволяє вбудовувати дані (у цьому випадку - цифровий підпис) в останні біти кольорових каналів пікселів зображення

Кожен піксель містить 3 канали: червоний, зелений та блакитний (RGB). Канали можуть мати значення від 0 до 255, й чим більше значення, тим інтенсивніший колір. 

Бінарно, кожне значення каналу складається з одного байту, який можна розкласти на 8 бітів (0 або 1)

Для шифрування повідомлень метод **LSB** використовує останні біти в каналах, а також ASCII таблицю, яка дає можливість перевести літери та символи в числові значення, а згодом і в бінарні. 

До прикладу, для того щоб закодувати 0, який в таблиці має значення 48 й в бінарному форматі виглядає як *0110000*, потрібно використати 3 пікселі. Піксель має 3 канали в кожен з яких (окрім останнього 3го) передається по одному значенню (0 або 1). 

При зміні одного біта в каналі, відмінностей в зображенні з прихованими даними майже не помітно, що значно ускладнює пошук. 

Метод можна використовувати як непомітну водяну марку на роботах\зображеннях, для підтвердження автентичності цифрових версій дипломів, захисту авторських прав тощо.
